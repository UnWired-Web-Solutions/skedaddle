# Google Search Console Access Status

**Verified on August 19, 2026**

The `uws@unwiredwebsolutions.com` account has verified-owner access to the domain property `sc-domain:skedaddlewildlife.com` in Google Search Console. The account can view the Search Results performance report, URL Inspection, indexing, sitemaps, experience reports, links, and property settings.

This confirms the required property access for the DashThis replacement. A production API integration still requires either a Google Cloud service-account JSON key added as a Full user to this property or an OAuth connection that produces a securely stored refresh token. Until one of those is configured, the portal can only use manually exported Search Console files.
